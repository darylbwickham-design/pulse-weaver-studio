# Pulse Weaver 2.0.0 unstable 4

Build my show has been rebuilt around five click-through phases: **Start → Sections → Looks → Sources → Review**. The wizard matches the main UI's raised navy/cyan controls, uses focused screens for details and explains what each choice changes.

- Start with Full show, Game and content, or Conversation, then customize the selected sections.
- Preview a Look without including it; open Configure for its framing. Landscape and portrait Stage transitions have separate tabs, including existing and new stingers.
- Reuse sources through focused choices. Optional shared layers start deferred and retain their draft answers when toggled off.
- Review actual assignments and edit the relevant source directly. Back preserves the current session's answers; Create my show remains the explicit commitment.
- Use contextual Lumia help and post-creation checks for picture, movement, sound and destinations. Planning diagrams do not open live sources or claim a successful connection test.

The Show output/status and broadcast controls are above the previews and mixer. Expanded audio retains its content-based sizing. The unused portrait bitrate control for landscape-only Kick is hidden.

Native movement, dual canvases, multistream, stingers, Lumia compatibility and existing audio/monitoring settings are retained. New browser sources still start with output audio off. No encoder, audio-route or source-shutdown policy changed. This revision adds no live preview decoders or idle polling to the wizard; CPU/RAM savings have not been measured.

Validation includes the native build, **2,143 preservation checks**, **188 readable Windows Qt checks**, strict layouts at three sizes and an actual isolated Windows walkthrough that created a logo-only show on both canvases. Live delivery, game-load performance and real stinger/Lumia audio playback remain separate rehearsal checks.

Use Studio → Updates with unstable builds enabled. This release supplies both `PulseWeaver-Setup-2.0.0-unstable.4.exe` for the ordinary unstable installation and `PulseWeaver-2-Preview-Setup-2.0.0-unstable.4.exe` for the separate 2 Preview installation. Each retains its existing installation identity and recovery path. Close Pulse Weaver and stop outputs before running setup. The Lumia 1.4.4 companion and existing wizard artwork remain compatible.
