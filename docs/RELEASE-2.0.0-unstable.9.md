# Pulse Weaver 2.0.0-unstable.9 — Combined chat without Discord

Choose **All chats (no Discord)** in the main chat read filter to show Twitch, YouTube and Kick together. Discord stays connected, ready to view again through All chats, Discord or an individual channel.

The selection applies to existing rows, newly arriving messages and Discord refreshes. The send composer and saved Discord channel choices keep their existing behaviour.

Discord message accents use Discord blue. Discord channels no longer receive an unrelated landscape-output label.

Both regular unstable and isolated 2 Preview installers are provided. This is a desktop change; no bot permissions or server settings change.
