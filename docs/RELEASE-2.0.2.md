# Pulse Weaver Studio 2.0.2

This Windows release adds the printable **Pulse Weaver Studio: The Nerds' Introduction** manual to the installed application and the Lumia Stream companion plugin.

## In Pulse Weaver Studio

- **Studio → Help → Open Pulse Weaver Manual** opens the bundled offline manual in the default browser. The manual is laid out for screen reading and printing.
- **About Pulse Weaver** now shows the installed Pulse Weaver release version and provides a manual button.
- The Help menu uses Pulse Weaver entries for the manual, website, community, diagnostics, release notes, About, privacy and terms. The OBS Help portal, OBS website, OBS Discord, What's New and OBS release links no longer appear in the Studio Help menu.
- The Show Control header shows the installed release number from the packaged release identity in place of the fixed 2.0 preview label.

## Lumia Stream companion 1.5.2

- The **Open Pulse Weaver Manual** action opens its own bundled offline copy when the Lumia integration is connected. The bundled file and setup guide remain available for direct opening without a Pulse Weaver connection.
- Setup, actions and tutorial help point to the manual. The plugin keeps the existing `pulseweavermotionpreview` ID and established show bindings.

## Manual scope

The book explains Pulse Weaver's differences from OBS, Stages, Looks and scenes, live show examples, setup and troubleshooting. It includes a glossary, index and the public Stream Studio release records published through 2.0.1. This 2.0.2 note records the documentation distribution update.
