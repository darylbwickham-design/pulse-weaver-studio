# Pulse Weaver 1.14.2 experimental alpha 5 — chat footer spacing

The chat status text above the destination selector and the **Send to** label now
have a matching 10-pixel left inset, aligning them with the text inside the chat
filter and message field. The status text also has 4 pixels of vertical padding
and a right inset for longer messages that wrap.

This alpha includes the themed show builder and other improvements from alpha 4.

Enable **Studio → Updates → Include experimental alpha builds**, stop outputs,
then check for updates. The installer uses the existing backup and restore flow
and bundles Lumia plugin 1.4.1.
