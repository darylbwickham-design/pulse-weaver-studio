# Pulse Weaver 1.14.2 alpha 7 — named chat panels and portrait wizard fixes

Show Control now supports independently named web chat panels inside its existing Chat card. Click the plain white heading to switch between native Chat and your saved panels. Click the chat icon and choose **Add chat…** to enter a name and web link. There is no heading dropdown or button box.

Each panel remembers its own link and page size. The icon menu offers editing, reload, browser opening and removal for the selected web panel. Lumia is supported through the same generic add flow; its view options appear only for a selected Lumia link. New Lumia panels use the focused Chatbox at a suitable size when that URL is supplied. Existing configured links and explicit sizes are preserved. Saved page size is reapplied after loading, including navigation between services.

The setup wizard now keeps portrait camera wrappers and browser viewports on their destination canvas. Landscape and portrait title/countdown artwork are assigned separately, and incompatible full-canvas browser sources are excluded from the corresponding choices. Reusable captures and source movement between Looks remain available.

The release retains the four-page setup flow, shared Lumia templates and companion plugin **1.4.4** from alpha 6. The updated template bundle includes the previously published Ending logo and portrait Breaking News alignment refinements. Chat panel selection controls the displayed page; native chat events remain available for Action rules, and this change does not promise YouTube receiving-quota savings.

Enable **Studio → Updates → Include experimental alpha builds**, stop outputs, then check for updates. Setup uses the existing verified backup and recovery flow and preserves your configuration during an upgrade. The release package contains application files, public template assets and setup guidance. It contains no personal profiles, account tokens, browser logins or local settings.

Validation includes native builds, generic chat preferences and lifecycle checks, wizard generation and canvas isolation, native panel switching and restart checks, installer payload/recovery tests and clean release audits. Separate-account Lumia template import and populated contributor Credits retain their existing testing limits.
