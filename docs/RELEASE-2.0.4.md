# Pulse Weaver Studio 2.0.4

The Stage button now shows the applied Look when one is active. Open **Control** to edit a Look and set each layer to **Show**, **Hide**, or **Leave as is**. Leave as is excludes that layer's visibility and position from the Look.

The Lumia bulb shows whether the keypad is connected. Hover over it to read the last keypad result. With the updated Lumia companion, Pulse Weaver can confirm whether Lumia accepted the alert. To limit a button to a Look, edit it in the keypad panel and choose a **Required Look**. Existing buttons allow any Look by default.

Right-click the globe in Show Control and choose **Refresh current Stage** to reload browser sources assigned to that Stage, including sources in nested scenes. Left-click still refreshes all browser sources. The old Backstage, Marquee, and Electric shortcuts have been removed from Studio and Setup.
