# Pulse Weaver 1.14.0 unstable 8

This preview makes Look creation and editing visible in Show Control.

- **Edit selected look**, **+ New look**, and **Duplicate look** now sit beside the Look choices. Selecting a Look loads its saved layout into the design canvases; Edit selected look points to its layers and keeps the live output unchanged.
- The editor names the Look currently being edited and tells you to arrange a layer and save it. Duplicate look now checks for unsaved changes before switching drafts.
- The quick start guide explains the new controls and the difference between saving a Look and running it live.

This update does not change installed scenes, credentials, port numbers, or output routing. The packaged Control page has not received a full visual click-through or live broadcast test.
