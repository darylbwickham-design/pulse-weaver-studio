# Pulse Weaver 1.13.0 alpha 2

This update removes two interruptions from the Windows app. YouTube privacy consent now appears when you choose to connect YouTube, immediately before Google sign-in, instead of during startup. If the current privacy notice has not been accepted, YouTube remains disconnected until you connect it. Existing account data is not deleted.

If Pulse Weaver crashes, it still saves a local crash log, but no longer opens OBS's native crash-log dialog. The installer retains the alpha channel's verified backup and rollback flow, along with existing profiles, credentials, and configured ports.

Downloads: `PulseWeaver-Setup-1.13.0-alpha.2.exe`, `PulseWeaver-Lumia-1.4.0.lumiaplugin`, and `SHA256SUMS.txt`.
