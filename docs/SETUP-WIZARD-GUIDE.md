# Create your show

Open **Show Control → Control → Build my show…**. The wizard has one flow with layout options available by default.

A **Stage** is a part of your show, such as Starting or Game. A **Look** is a layout you switch to inside a Stage. A **source** supplies a camera, capture, image, video or browser overlay. Each Look has coordinated landscape and portrait versions.

You can reuse existing sources or create new ones in the wizard. Feed A, B and C are assigned independently for each stage group; a feed can use the same source as another group or a different one. Optional feeds can be skipped. Reuse an existing camera source when it already uses the device you want.

1. **Set up Lumia and prepare your artwork.** **Lumia Stream is required for the supplied overlays, countdown and widgets.** Page 1 groups installation, the Pulse Weaver plugin and overlay imports together. Use **Download the Pulse Weaver Lumia plugin**, or [download the companion plugin here](https://github.com/darylbwickham-design/pulse-weaver-studio/releases/latest/download/PulseWeaver-Lumia-1.4.4.lumiaplugin). Import its `.lumiaplugin` file into Lumia and follow its connection instructions. **Get Lumia overlays and setup instructions** opens the template links and guidance. Import the templates you need, then copy their browser links for page 4. The checkboxes are readiness reminders; they do not verify a connection or run commands. You can keep planning while finishing Lumia setup.
2. **Choose stage groups.** Name this new show and click the cards for Starting, Chat, Game, Projects, Celebration and Intermission as needed. The suggested name avoids existing shows. If you enter a name that clashes with one of your selected Stages or scenes, the wizard asks for another name here. Ending and BRB belong to Intermission.
3. **Choose functional Looks and options.** Click the operating Look cards you need and use Next stage to continue through your groups. The diagram follows the tab or Look you choose. Recommended layouts work without opening extra controls. Click Layout options… to adjust composition, fit/crop, inset position and portrait proportion using direct choices. Compatible saved presets retain their framing and camera treatments. Expand **Stage transitions (optional)** to choose Fade, Cut or an existing stinger independently for landscape and portrait. The Profounder link is beside these controls. **Add stinger…** accepts a local video, such as MP4 or WebM, and its cut point in milliseconds. Images and documents are rejected. A new stinger can be reused in other stages and is applied only where selected.
4. **Assign sources and review.** Assign Feed A, B and C according to each question. The status marks required and optional questions and shows your progress. **Next source needing attention** jumps past completed and empty optional questions; **Review source assignments…** opens searchable cards for any assignment. Click **Use existing…** or **Create new…** for a camera, capture, image, video or browser link. New sources can be reused and edited before creating the show. For artwork and countdowns, use an existing Lumia browser source or click **Paste Lumia link** and enter an imported template's browser link. Click **Next source** after each valid assignment, or **Skip this optional source** for an unused input or layer. Each Look has separate H/V artwork choices. A browser artwork draft created for one orientation is offered only in that orientation's artwork choices; create its matching counterpart separately. The diagram follows the source question. Review both canvases and choose **Create my show** with streaming and recording stopped.

There are **three shared alert / overlay layers per canvas**. Layer 1 is lowest; layer 3 is highest. Each can use an existing source or a new one, and can target all selected Looks, one stage group or one Look, including copied saved layouts. These assignments apply to the new show. Unused layers can stay empty. Use matching landscape and portrait artwork; no extra alert Stage is required for ordinary alerts.

Full-canvas artwork, including the Lumia templates, covers the canvas. Use the artwork placement option when an asset belongs in a smaller panel instead. Related Looks share sources so Pulse Weaver Move can animate between them. A stinger runs when switching Stages; it does not replace movement between Looks within one Stage. The guide links to [Profounder](https://profounder.com/transitions/) for stinger videos. Keep a chosen file in place, then preview and adjust it in **Camera → Scene Transitions** after creation. If the panel is hidden, show it through **Studio → Docks → Scene Transitions**.

New sources and stingers are drafts until **Create my show**. Cancelling discards them. Existing shows and source settings remain available; reusing a source also shares later changes to that source's properties. The diagrams show placement, not live feeds. After creation, keep outputs stopped and check the actual cameras, artwork, audio and transitions on both canvases in Control. Configure microphone, desktop audio and output routing in Settings separately.

## Lumia overlays and actions

The Lumia bulb beside the readiness status on **Show Control** opens the same guide available in the wizard. It contains all twelve import links, countdown start and completion instructions, Chat Physics setup, Fortnite challenge setup and stinger guidance. Other supporting services can accompany Lumia in this area later.

Import only the required MAIN, READY, BRB, END, ALERT and NEWS families. H means landscape and V means portrait. Customize text, logos, colours and artwork in Lumia. An import link is different from a browser source link: after importing, use Lumia's chain / copy-link button and assign that link to the correct canvas.

Newsroom is visible on load by default. For an event-only news intro, import a separate copy and turn off **Show persistent Newsroom on load**. Give each Look the intended overlay copy.

Assign MAIN to Countdown, READY to Getting ready, BRB to Be right back and END to Ending. Add NEWS through the shared overlay questions and choose its intended Look. Match H/V artwork to the canvas. If you later deselect an overlay's target, choose another target or skip that overlay before creating the show.

Import ALERT01-H's accompanying commands once. Its two chat controls and five disabled reward-code helpers serve both orientations. Copy the helpers into your own Twitch Points rewards and choose costs and permissions. The portrait copy carries no duplicate commands. New browser sources start with output audio excluded; existing browser audio settings are preserved. Enable audio for one intended source in audio routing after creation and keep its other canvas copy silent, so alerts, TTS and effects do not play twice.

The shared Lumia countdown starts through the `start-screen` payload described in the guide: `{"action":"start","durationSeconds":600}` starts ten minutes. A Pulse Weaver **Run Stage Look / Motion Action** selects the Starting Countdown Look; the separate payload starts the timer. Send the payload once for both formats.

To switch when the timer reaches zero, create your own Lumia command, for example `countdown-finished`, containing Pulse Weaver's **Run Stage Look / Motion Action** with the next Stage / Look selected. In one Starting overlay's Lumia settings, set **Your countdown completion command** (`goLiveCommand`) to that command name and enable **Run completion command (enable on ONE canvas only)** (`autoFireGoLive`). Leave this off in the other orientation and any other timer copies. The shared templates start with completion disabled and the command blank. Choose one command owner across all timer instances, separately from the one audible owner for overlay sound. Starting a broadcast is a separate action; only add it to your command if that is intended.

With outputs stopped, select the Starting Look, send a short countdown, and confirm it calls your command exactly once and reaches the intended next Look. The Lumia bulb on Show Control keeps these start, stop and completion instructions available after the wizard closes.

Native Credits use Lumia's session data. Repeated activation uses the tested viewer compatibility bridge; populated session entries and separate-account import still need acceptance testing.

## Chat Box Physics

Open [Chat Box Physics in the Lumia plugin marketplace](https://lumiastream.com/plugins#chat_physics_local), confirm the creator is **TangoTiddies**, and choose **Install Plugin on Lumia Stream**. Enable it in Lumia. Its installed settings and actions may use the internal name **Chat Physics Local**. Enable **Lumia Settings → API → Developers API** and put its token only in the plugin's **Connection → Lumia Developers API token** setting. Use Lumia's displayed API port, normally `39231`, with host `127.0.0.1`.

On wizard page 4, Chat Physics is suggested in **shared overlay layer 2** for both formats. Click **Use default Chat Box Physics link** to fill the matching URL: `http://127.0.0.1:39270/` for landscape and `http://127.0.0.1:39270/portrait` for portrait. You can choose another free layer. Enter the plugin's **Local overlay port** if changed. These are separate browser sources, with source viewports **1920 × 1080** and **1080 × 1920** respectively. Fit each to its destination canvas. Choose which Looks should show it and keep source shutdown and scene-activation refresh off so cards survive Look changes. One plugin connection feeds both formats.

To coordinate chat with a camera layout, put **Change Chat Camera Clearances**, **Change Chat Physics Mode** and Pulse Weaver's **Run Stage Look / Motion Action** in the same Lumia command. Set each action's **Output** to Landscape, Portrait or Both as appropriate. Clearances reserve source pixels above, below and beside upright chat; choose **Upright chat box** or **Compact single line** and the desired placement. Different camera layouts usually need separate H/V settings. Clearances do not make chat automatically follow moving cameras, and physics modes use their own placement areas.

Set **Revert after seconds** to **0** to keep the selected chat layout. A positive value is a hold time before reverting, not the animation duration. Existing cards keep their mode; use **Clear existing cards first** when the whole presentation should change. **Restore Saved Chat Layout** returns the selected output to its saved layout. Use **Preview Chat Physics**, then a connected chat message, to check both outputs with streaming and recording stopped. The **Chat Physics** topic in the Lumia bulb guide provides the full steps and troubleshooting.

## Choose your chat panel

Named web chat panels are available in Pulse Weaver 1.14.2 and later.

On **Show Control → Show**, the heading keeps its original plain white style. Click its text to cycle through native **Chat** and your saved panels, shown by the names you choose. Click the adjacent emblem and choose **Add chat…** to enter a **Name** and complete HTTP or HTTPS **Link**. You can add any compatible web chat page. Each panel keeps its own name, link and page size; editing one panel does not replace another. The page appears inside the main Chat card, which retains its normal 270 px minimum width.

With a saved panel selected, its emblem menu offers **Edit this chat…**, **Reload**, **Open in browser**, **Page size** and **Remove this chat panel**. Returning to **Chat** restores Pulse Weaver's usual feed and controls; its emblem offers the generic **Add chat…** action.

For example, name a panel **Lumia** and use `https://lumiastream.com/dock/chat` for its focused Chatbox. A new Lumia panel starts at **67%**; other new panels start at 100%. Saved sizes are retained independently. **Lumia view** options appear only when the selected panel's link uses the exact `lumiastream.com` or `www.lumiastream.com` host. They switch that panel between **Show Lumia chat only** and **Show full Control Room**. The native Chat menu provides the same generic add flow for every service.

External pages use the current app's shared browser context and retained login storage. Visited pages remain loaded when you return to **Chat**, select another panel or leave the Show view, preserving drafts and scroll position. **Reload** refreshes only the selected panel. Removing a panel or closing Pulse Weaver closes its page. Sign in to a third-party service yourself when it asks. Pulse Weaver's connected chat events remain available to Action rules. Changing the displayed panel does not promise reduced YouTube receiving quota: the current incoming YouTube reader already uses web chat.
