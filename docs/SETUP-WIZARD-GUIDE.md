# Create your show

Open **Show → Control → Build my show…**. Choose the results you need first. There are two required pages.

## 1. Choose your layouts

Select any combination of the live layout cards: Camera, Face + activity, Activity + face, Screen share, Screen + two cameras, Gameplay, and Game + two cameras. Select Starting, Break, Ending or Celebration / announcement if you need those screens. Nothing is selected automatically, and no unused layout is generated.

“Activity” means a work area, demonstration, instrument, pet, maker camera or another subject. It is not tied to a particular streamer's printer or custom game layout. Camera sizes and colour treatments are optional adjustments, rather than extra template variants.

**Use a saved show layout / detailed setup…** retains the detailed builder for saved shows and specialist arrangements.

## 2. Set up & build

Name the show and choose only the inputs the selected layouts need. Game, screen, face camera and activity camera are separate assignments, shared between the layouts. **Choose existing…** opens the input cards directly. **Add new…** configures a device, capture, image, video or browser input as a draft. A face camera is optional for the basic gameplay, screen-share and activity layouts. Layouts explicitly showing two cameras require two different pictures. A show containing only Starting, Break or Ending asks for no captures.

Browse the landscape and portrait arrangement illustrations with the arrows. Wide games and screens fit completely; filling a tall frame would require cropping. New or inactive captures use an estimated 16:9 illustration until their actual dimensions are available. Confirm the real pictures after creating the show.

The optional customisation cards open focused editors:

- **Camera framing & colour:** fit or crop cameras, set the landscape inset size and corner, adjust portrait camera height, or add monochrome. Existing capture filters remain in place. Monochrome belongs to a new native wrapper scene, which reuses the capture rather than opening another device.
- **Stingers & transitions:** choose Fade, Cut, or an existing/new stinger independently for landscape and portrait. Transitions between Stages are separate from movement between Looks.
- **Alerts · up to 3 layers:** reuse provider browser overlays or paste their actual browser links. Use one responsive link for both formats or assign separate links. Layer 3 sits above 2 and 1. Choose all screens or Main layouts only. New browser copies start silent; enable one intended audio copy in the mixer after creation. Existing audio and monitoring settings are retained.
- **Screen messages & artwork:** edit static holding messages or use provider browser artwork for countdowns and animated scenes. Built-in Starting is a static message, not a running timer. An unassigned format keeps a built-in image fallback.

Back preserves selections and assignments. Cancel in an optional editor restores its prior answers. Cancel in the wizard creates no partial show. Closing and reopening starts a fresh draft.

Stop active outputs, then choose **Create my show**. The live layouts become Looks in one shared Main Stage; selected surrounding screens become their own Stages. Existing shows and source settings remain. Creation does not start a broadcast, connect a guest call, or verify provider commands. Check the actual framing and alert audio before going live.
