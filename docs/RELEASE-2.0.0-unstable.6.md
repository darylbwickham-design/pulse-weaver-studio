# Pulse Weaver 2.0.0 unstable 6

Build my show now has **two required pages: choose your layouts, then set up and build**. Select the results you need before supplying inputs. Framing, colour, stingers, alerts and artwork are optional focused editors.

- Choose Camera, Face + activity, Activity + face, Screen share, Screen + two cameras, Gameplay and Game + two cameras, plus optional Starting, Break, Ending and Celebration screens. Camera sizes and colour are adjustments, not duplicate presets.
- Bind game, screen, face and activity inputs separately. One input is reused across its Looks and both canvases. A basic game/screen/activity layout can omit the face camera; starting-only shows ask for no captures.
- Set camera fit/crop, landscape inset size/corner and portrait camera height. Optional monochrome uses a native filtered wrapper without changing the original camera's filters or opening another capture.
- Keep separate landscape/portrait stingers and up to three paired alert layers. New browser copies start with output audio off; select one intended audible copy and rehearse. Existing audio and monitoring remain unchanged.
- Use editable static holding messages, or supply your provider's browser artwork for countdowns and animated scenes. The built-in Starting screen is a static image, not a timer.
- Back retains selections and assignments. Cancelling an optional editor restores its prior answers. Create appends an editable show while preserving existing catalogue entries. Saved layouts remain available through detailed setup.

The coverage review used the whole Q3 command group, rather than misreading Q3 as a count of three. Printer arrangements become general activity-camera layouts; bespoke Yu-Gi-Oh layouts and stream-specific graphics are not wizard templates. See the [design rationale and coverage mapping](SETUP-WIZARD-SELECTION-FIRST-2026-10-26.md) and [setup guide](SETUP-WIZARD-GUIDE.md).

Verification covers every individual offered result, a combined show, camera-free gameplay, original colour-filter preservation, three alert layers, both canvas geometries, Back/cancel and the real production Finish path with an existing catalogue. The full motion/regression suite and readable Windows checks run against frozen sources. Native visual and installer/update checks accompany the release validation. These checks are not an independent novice usability study, a live-provider rehearsal or a claim of lower CPU/RAM use.

Use **Studio → Updates** with unstable builds enabled. Ordinary installations use `PulseWeaver-Setup-2.0.0-unstable.6.exe`; separate 2 Preview installations use `PulseWeaver-2-Preview-Setup-2.0.0-unstable.6.exe`. Each keeps its installation identity and recovery path. Stop outputs and close Pulse Weaver before setup. The Lumia 1.4.4 companion and existing wizard artwork archive are unchanged.
