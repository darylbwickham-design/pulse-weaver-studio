# Pulse Weaver 1.14.4-alpha.1 — clearer guided show setup

Build my show now presents stage groups, Looks and source choices as clickable cards. Optional layout settings and transitions open when needed. The preview follows the current stage, Look and source question, and inactive questions no longer leave a large blank space.

Each stage can reuse existing inputs or create new cameras, captures, media and browser sources. Required source questions explain what remains to be added; optional questions can be skipped. New sources can be reused in other stages. Landscape and portrait artwork stay on their intended canvas, including when replacing artwork in saved layouts. Lumia share and download pages are rejected as browser source links; use the browser link supplied by Lumia after importing a template.

Stingers can be selected separately for landscape and portrait from existing transitions or readable local video files. Images and documents are rejected before any show changes are made. Duplicate show names are detected earlier, with a suggested unused name.

The Lumia instructions have been clarified for first-time setup. This release includes the Lumia companion plugin 1.4.4 and the current overlay template bundle. Lumia is required for these supplied overlays, countdown and widgets. The bulb on Show Control explains plugin and template import, the countdown completion command and Chat Box Physics mode changes.

After installing, open **Show Control → Control → Build my show…**, follow the four pages and review both canvases before creating your show. The installer preserves your local configuration. This is an alpha preview; 1.14.3 remains the latest regular release.

Validation: the native Windows build and the focused wizard, source and transition checks passed, followed by a visual check of all four pages in the isolated installation. The public package is built from clean runtime files and excludes account tokens, browser profiles and personal settings.
