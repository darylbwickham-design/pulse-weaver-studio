# Pulse Weaver 1.14.2 alpha 6 — setup wizard and Lumia overlays

Build my show now follows one four-page setup flow: connect Lumia, choose stage groups, choose functional Looks and their layout options, then assign sources and review both canvases. The broader options are available by default. Existing compatible saved layouts can be reused with their independent landscape and portrait framing.

- Choose Starting, Chat, Game, Projects, Celebration and Intermission independently.
- Choose functional Looks without creating extra Looks for camera treatments or branding options.
- Add a persistent Newsroom overlay, or a separate event-only news intro.
- Open Lumia setup guidance from the bulb beside the readiness status on Show Control, or from the wizard.
- Import twelve shared Lumia templates for Starting, Getting ready, BRB, Ending with native Credits, alerts with Fortnite challenges, and Newsroom. Each family has landscape and portrait versions with editable branding.
- Follow the countdown and Stage-switch instructions, connect your own Twitch rewards, and choose optional stingers through Profounder.

This release includes the existing alpha branch's Lumia undo action and companion plugin 1.4.3. It is an experimental alpha release; the regular release remains 1.14.1.

Enable **Studio → Updates → Include experimental alpha builds**, stop all outputs, then check for updates. The installer preserves configuration using the existing backup and recovery flow.

The template links import into Lumia. After import, copy each overlay's own browser link into Pulse Weaver. ALERT01-H includes seven command actions once: two chat controls and five disabled reward-code helpers. Users connect those helpers to their own Twitch Points rewards. Portrait playback should have one shared audio owner with landscape.

Validation covers native builds, wizard generation and rollback, saved layout preservation, motion behavior, update and installer checks, Lumia command tests, and clean release packaging. Separate-account Lumia import and populated contributor Credits remain to be tested. No live broadcast or reward was triggered during verification.
