# Pulse Weaver 1.14.3 — Lumia guided show setup

Build my show now uses Lumia browser sources for artwork, countdowns, chat and shared overlays. Each selected Look has separate landscape and portrait artwork, while stage feeds can reuse existing sources or create new camera, capture, media and browser inputs. Three shared alert layers per canvas support both new and copied saved layouts. Older saved native artwork must be replaced with correctly oriented Lumia browser sources.

The wizard suggests Chat Box Physics in shared layer 2 for each canvas, links to its Lumia marketplace listing and can fill the correct local browser URL. The Lumia bulb on Show Control explains importing templates, starting the countdown, running a chosen command when it reaches zero, and coordinating Chat Physics mode and camera clearances with Look changes. Optional landscape and portrait stingers can be added from local video files, with a cut point for each.

The four wizard pages, source controls, diagrams, logo and icons have been refined for first-time setup. The Overlay Designer now fits the available screen and scrolls its controls. The inactive header reads Stream idle and Recording idle.

Validation: native Windows build and 1,934 MotionAudit checks passed, including Lumia-only source validation, saved-layout replacement and orientation, shared layers and stinger creation. The isolated installation was updated without copying settings; the main installed copy was left unchanged during testing.

After installing, open **Show Control → Control → Build my show…**. Follow the Lumia setup prompts and check both canvases before starting a stream. The installer retains your configuration through its existing backup and recovery flow.
