# Pulse Weaver 1.13.1 alpha 5

This alpha includes the guided Show setup and Game Capture controls from alpha 4. On a fresh setup, **Build my show** now appears beside the Stage selector. It was previously clipped outside the layout, so new users could miss the entry point.

The guide is [Build a show](BUILD-MY-SHOW-GUIDE.md). The wizard can use existing sources or create new cameras, game and screen captures, browser overlays, and stage graphics. It builds Starting, Hangout, Gameplay, BRB/Ending, and Celebration stages with landscape and portrait looks. Existing scenes remain available. The main Show page also provides a Game Capture window picker.

The desktop build succeeded. In a disposable portable profile with no saved Stage catalogue, the Show page displayed **Build my show** beside the Stage selector and opened the wizard. Previous alpha 4 checks built five stages and eight looks from temporary sources. No live stream, connected account, installer, or installed user profile was used in these checks. The in-menu alpha updater retains the installed profile and creates its verified backup.
