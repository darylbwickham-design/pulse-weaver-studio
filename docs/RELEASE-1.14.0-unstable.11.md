# Pulse Weaver 1.14.0 unstable 11

This unstable showcase contains the same audited application and companion plugin as **1.14.0 experimental alpha 4**, with the unstable updater identity.

It includes the YouTube request/lifecycle refinements, Twitch/Kick callback fixes, saved-look and source-identity corrections, stage/audio/settings safeguards, storage preservation and installer recovery hardening described in the [alpha 4 notes](RELEASE-1.14.0-alpha.4.md). The companion Lumia plugin is **1.4.1** and keeps existing action IDs and bindings.

This remains a prerelease. Live quota savings are not yet measured. Save quota can add up to 30 seconds during quiet chat; Responsive is available. The [source audit](PULSE-WEAVER-SOURCE-AUDIT-2026-09-29.md) lists verification and remaining source-addition/container-rename limitations.

Downloads: `PulseWeaver-Setup-1.14.0-unstable.11.exe`, `PulseWeaver-Lumia-1.4.1.lumiaplugin`, and `SHA256SUMS.txt`.

Choose **Studio → Updates → Include unstable showcase builds**, or install the matching download. The installer updates regular Pulse Weaver, verifies a recovery backup and preserves profiles, scenes and connection settings. Stop all outputs before updating.
