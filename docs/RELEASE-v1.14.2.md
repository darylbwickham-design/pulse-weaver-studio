# Pulse Weaver 1.14.2 — layout setup and retained chat panels

This regular release brings the 1.14.2 preview improvements into the normal update channel. Build my show follows four pages: connect, choose stage groups, choose functional Looks and layout options, then assign sources and review both canvases. Broad options are available by default, with compatible saved layouts available for reuse. Portrait camera wrappers and browser viewports stay on their destination canvas.

Show Control supports named web chat panels alongside native Chat. Click the plain heading to switch panels; use the chat icon to add or manage a web link. Visited panels remain loaded, preserving drafts and scroll position. Each remembers its own page size. Lumia-specific view options appear only for Lumia links. Native chat events remain available for Action rules; selecting a web panel does not promise YouTube receiving-quota savings.

The layout wizard now assigns artwork separately for each Look and canvas. Countdown, Getting ready, BRB and Ending can use different Lumia templates within their shared Stage. Previously a group's Looks shared one artwork assignment. Generated Looks now show their own artwork and hide the others while preserving shared feed identities. Newly added browser overlays stay loaded while hidden so Look switches preserve their timer and widget state.

Extra overlays can target one selected Look, an entire selected stage group or all new layout Looks. This lets Newsroom appear only in its intended presentation. Deselecting an overlay's target prompts you to retarget or skip it instead of silently dropping the overlay.

Lumia template import links are rejected as browser URLs, with instructions to import the template and copy its browser link. Countdown minutes appear only for the built-in countdown; the guide explains that Lumia countdown duration comes from its start action. Setup guidance also explains when to add cameras and stingers, maps the published artwork families to their Looks, and makes clear that imported Fortnite helpers still need your own reward bindings and costs. The wizard initially sizes itself to the available screen.

Includes shared decoded stinger frames, preview/readiness refinements, companion plugin **1.4.4** with the previous Stage/Look undo action, and twelve shared landscape/portrait Lumia templates. The Show Control bulb opens setup guidance, including countdown and Stage-switch actions, optional Profounder stingers and user-owned reward bindings. Existing shows, saved layout presets and older shared-artwork requests remain compatible.

Validation: native build and **1,736 isolated motion/wizard checks**, including separate BRB/Ending artwork on both canvases, visibility when switching Looks, overlay targeting, retained browser settings and transactional rejection of invalid assignments. Release assets contain application files and public templates, with no personal profiles, Lumia tokens, browser logins or local settings.

Separate-account Lumia template import and populated contributor Credits retain their existing testing limits.

Stop outputs and check **Studio → Updates**, or download **PulseWeaver-Setup-1.14.2.exe** below. Alpha opt-in is not required. Setup preserves configuration through the existing backup and recovery flow.
