# Pulse Weaver 1.13.1 alpha 3

Stream Details now presents Twitch and Kick in matching sections. Each has a full-width title field, a searchable category field, separate **Update Title** and **Update Category** actions, and feedback beside the controls. Updating one field sends only that field to its platform. The wider card keeps both category searches readable. YouTube's next-broadcast title remains in its own section.

The change was checked in the separate portable preview: Twitch and Kick category searches returned results, and the controls were visually aligned. No live title or category update was sent. The installed profile, streaming routes, OAuth connections, Lumia API, and Cloudflare relay are unchanged by this update. The in-menu alpha updater backs up the installation before replacing app files and retains scenes, settings, credentials, and ports.
