# Pulse Weaver 1.12.17

YouTube privacy consent now appears when you choose to connect YouTube, immediately before Google sign-in, instead of during startup. If the current privacy notice has not been accepted, YouTube remains disconnected until you connect it. Existing account data is not deleted.

If Pulse Weaver crashes, it still saves a local crash log, but no longer opens OBS's native crash-log dialog. The installer continues to back up and retain existing profiles, credentials, and configured ports. Release remains the default update channel for fresh installations.

Downloads: `PulseWeaver-Setup-1.12.17-BETA.exe`, `PulseWeaver-Lumia-1.4.0.lumiaplugin`, and `SHA256SUMS.txt`.
