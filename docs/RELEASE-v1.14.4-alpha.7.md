# Pulse Weaver 1.14.4-alpha.7 — Platform-coloured sliding controls

Show Control's format choices now use one consistent 47 × 28 px option size across Twitch, YouTube, Kick and recording. The raised selection thumb slides into place when clicked. Unselected choices and their track are grey; the thumb uses Twitch purple, YouTube red, Kick green or yellow-orange for recording. Selected text uses a contrasting colour for readability.

The slide lasts 180 ms and stops when settled. Live previews also have a raised switch with a short slide, and the preview refresh handle has a matching finish. No animation runs continuously while idle. Preview, chat and bottom-bar geometry remain unchanged.

Recording retains **Default**, Off, 16:9, 9:16 and Both within the existing 240 × 32 px slot. Saved destinations, live-format restrictions, recording locks and keyboard controls remain in place. The full regular Alpha feature set, including replay buffer, Altron, stingers and chat providers, is retained.

Includes Alpha 6's preview controls and earlier setup-guide and installer fixes. Stop Pulse Weaver before running **PulseWeaver-Setup-1.14.4-alpha.7.exe**. Setup makes a verified backup and preserves your show, audio settings, accounts, API port and Lumia connection. The companion plugin remains 1.4.4; no plugin update is required for this UI refinement.

Alpha builds remain opt-in through **Studio → Updates → Include experimental alpha builds**. The regular release remains 1.14.3. Validation details accompany the release in `VALIDATION.txt`; live performance with every game or encoder is not certified by these UI checks.
