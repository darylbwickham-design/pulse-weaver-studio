# Pulse Weaver Studio 2.0.3

This Windows update adds a browser-source refresh button to the main Show Control header, beside the HUD and Lumia controls.

## Refresh browser overlays

Use the **Refresh all browser sources** icon beside HUD and Lumia to reload browser sources across every canvas, including inactive sources and sources inside nested scenes. Shared sources refresh once. The refresh bypasses the browser cache without changing saved source settings.

Use it after changing web overlays or when browser-source content needs reloading. The button briefly disables while the refresh batch starts and shows how many browser sources received a refresh request in its tooltip.
