# Pulse Weaver 1.13.0

This regular release promotes the tested 1.13.0 alpha 2 application without changing its runtime binaries. It includes the visual Motion stage editor, the refined stream layouts, deferred YouTube privacy consent, and local crash logging without OBS's native crash dialog.

The installer uses the regular update channel. It creates and verifies a complete backup before replacing an existing installation, and it preserves scenes, profiles, credentials, browser data, Lumia settings, and saved ports. The installer is named `PulseWeaver-Setup-1.13.0.exe`; it is a regular release, not an alpha or beta.

The matching Lumia plugin is `PulseWeaver-Lumia-1.4.0.lumiaplugin`. Existing regular-plugin manifest ID and action settings remain compatible. The separate Motion Preview plugin remains separate.

The Kick title and moderation fixes are in the following 1.13.1 alpha, not this promoted build.
