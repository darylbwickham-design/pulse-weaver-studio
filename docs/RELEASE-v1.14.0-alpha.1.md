# Pulse Weaver 1.14.0 experimental alpha 1

This alpha packages the same Show Control implementation as 1.14.0 unstable 8 for the Alpha update channel.

- **Edit selected look**, **+ New look**, and **Duplicate look** are visible beside the Look choices. Selecting a Look loads its saved layout into the design canvases; editing and saving do not change the live output.
- The Look editor names the selection and explains how to arrange a layer, save it, and run the saved Look live.
- The guided show builder, saved Look transition preview, and direct audio, recording and video controls from the unstable showcase are included.

The regular release remains 1.13.3. Alpha is opt-in under **Studio → Updates**. The installer creates and verifies a full backup before updating an existing installation and retains its profile, scenes, credentials and ports. This alpha uses the existing Lumia plugin format and bundles version 1.4.0.

The native build and installer self-checks passed. A full visual click-through and live broadcast test have not been performed for this alpha package.
