# Pulse Weaver 1.14.4-alpha.5 — Game Challenges setup guide

The Lumia setup guide shared by **Build my show** and Show Control's **Lumia bulb** now explains Custom Game Challenges 1.0.5: saved game profiles, the included 20 editable Fortnite challenges, native actions, five optional reward templates and the Next command. It covers the correct import destinations, disabled/unlinked defaults and manual Twitch reward linking. Next advances one challenge; Clear is a separate action with an explicit scope.

For a fresh plugin setup, skip PW-ALERT01-H's old challenge command bundle and disable its legacy challenge widget while retaining other alerts. The public alert templates do not automatically connect to the new plugin. Existing connected rewards and button 34 can be kept. Countdown, Newsroom, Chat Physics, Credits, stinger and companion connection instructions are retained.

Custom Game Challenges is a **separate optional Lumia plugin**. This Pulse Weaver update does not install it or change your rewards, prices, enabled states, queues or existing show. No new marketplace download link is claimed. The existing companion plugin and public overlay template bundle are unchanged.

Includes alpha 4's Altron support and alpha 2's configuration-preserving installer repair. Stop Pulse Weaver before running **PulseWeaver-Setup-1.14.4-alpha.5.exe**. Setup makes a verified backup and retains the existing configuration. Alpha builds remain opt-in through **Studio → Updates → Include experimental alpha builds**; the regular release remains 1.14.3.

Validation details accompany the release in `VALIDATION.txt`. Fresh-account public-overlay migration and real Twitch reward linking have not been certified by this guide update.
