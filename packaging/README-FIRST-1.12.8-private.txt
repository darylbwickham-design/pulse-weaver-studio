Pulse Weaver 1.12.8 BETA - Overlay repair and safe maintenance

Close Pulse Weaver before updating. Setup automatically creates and verifies a
full backup of app files and settings before committing the update. BACK UP NOW
creates an additional restore point. RESTORE BACKUP / ROLL BACK restores the app
version and settings together; it first backs up the state being replaced.

Backups are stored beside the installation in "Pulse Weaver Backups", outside
the folder removed by uninstall. Keep them private: they contain account data.
Encrypted credentials remain tied to this Windows account/machine.

Use the revised 1.12.7 RECOVERY installer with the pre-1.12.8 backup if needed.
Do not reinstall older binaries on top of newer overlay settings. The recovery
installer refuses that unsafe downgrade and offers backup restore instead.

Includes the native landscape/portrait Camera editor, overlay draft/publish
foundation, Alert Box v1 and the Astra audit repairs. Show Control remains the
live-output UI; overlay authoring is in Camera and triggers are in Action.

No personal configuration or platform credentials are embedded in this payload.
