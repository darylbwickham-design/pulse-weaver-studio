Pulse Weaver 1.12.15 Beta

Fixes an Overlay Designer selection callback that could run during window
destruction. Also strengthens scene-item lifetime handling, browser subscriber
cleanup, and local control API request handling and resource limits.

Close Pulse Weaver and previous setup windows, then run this installer.
Do not uninstall first. Setup creates and verifies a complete app and settings
backup before replacement. Existing scenes, source identities, transforms,
positions, overlays and account settings are preserved.

Use RESTORE BACKUP in maintenance mode to return to the prior app and its paired
settings. Backups can contain private account data; keep them private.
