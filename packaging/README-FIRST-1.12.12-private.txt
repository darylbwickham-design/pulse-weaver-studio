Pulse Weaver 1.12.12 BETA - Simplified YouTube connection screen

The YouTube connection screen no longer displays or edits the application
Client ID or Client secret. Connect, disconnect/revoke, output selection and
policy links remain available. Existing saved registration details are retained.

If an installation has no YouTube application registration, it now shows a
support message rather than asking users to enter developer credentials.
This update does not provision a YouTube registration on a fresh installation.

Close Pulse Weaver and any previous setup window, then run this installer.
Do not uninstall first. Full verified app-and-settings backups and rollback
remain enabled. Scenes, transforms, positions and account settings are preserved.

Includes the 1.12.10 Twitch chat repairs and 1.12.11 installer log-lock fix.
Privacy and Terms are bundled in docs. Keep backups private.
