Pulse Weaver 1.12.14 Beta

Repairs live 16:9 Camera editing. Moving, resizing, cropping or animating a
source in the scene currently on Stage now reaches the programme preview and
live output immediately; changing Stage is no longer needed. Destination scene
copies used for source exclusions are also reconciled every video frame so
Move-style animation cannot leave them stale.

Close Pulse Weaver and previous setup windows, then run this installer.
Do not uninstall first. The updater creates and verifies a complete app and
settings backup before replacement. Existing scenes, source identities,
transforms, positions, overlays and account settings are retained.

Use RESTORE BACKUP in maintenance mode if you need to return to the prior app
and its paired settings. Backups can contain private account data; keep them
private.
